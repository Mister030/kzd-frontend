# KZD Frontend development

Opdrachten uit het keuzedeel Frontend development (MBO Utrecht, Software Developer niveau 4). Twee websites nagebouwd vanaf een ontwerp: één in React en één in Vue, beide met SCSS.

| Map | Opdracht | Stack |
| --- | --- | --- |
| [`opdracht-1-alteco`](opdracht-1-alteco) | Website voor Alteco: topbar, hero, diensten, aanbiedingen en een scroll-to-top-knop | React, Vite, SCSS |
| [`opdracht-2-buildicon`](opdracht-2-buildicon) | Website voor BuildIcon, responsive uitgewerkt vanaf wireframes voor desktop, tablet en mobiel | Vue 3, Vite, SCSS |

## Starten

```bash
cd opdracht-1-alteco    # of opdracht-2-buildicon
npm install
npm run dev
```

## Wat zit erin

- Componenten per onderdeel van de pagina (bijvoorbeeld `Header`, `Hero`, `Services`, `Offers`)
- SCSS opgedeeld in variabelen, mixins, een grid en een bestand per component
- Bij opdracht 2: wireframes en een vergelijking tussen React en Vue in [`inleveren/`](opdracht-2-buildicon/inleveren)
